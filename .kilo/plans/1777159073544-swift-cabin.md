# Landing Website Plan: Anx Reader

## Objective
Create a Node.js/Next.js landing page for Anx Reader with:
- Neumorphism (Soft UI) design system
- English/Spanish bilingual support with automatic language detection
- Privacy Policy and Terms of Use pages
- Vercel deployment ready

## Tech Stack
- **Framework**: Next.js 14 (App Router) with TypeScript
- **Styling**: Tailwind CSS (customized for Neumorphism)
- **i18n**: next-i18next for translations
- **Deployment**: Vercel (native Next.js support)

## Implementation Steps

### 1. Project Setup
- Initialize Next.js with TypeScript and Tailwind
- Install dependencies: `next-i18next`, `i18next-browser-languagedetector`
- Configure Tailwind with Neumorphism design tokens

### 2. Design System Integration
**Colors (tailwind.config.ts)**:
```typescript
colors: {
  background: '#E0E5EC',
  foreground: '#3D4852',
  muted: '#6B7280',
  accent: '#6C63FF',
  'accent-light': '#8B84FF',
  'accent-secondary': '#38B2AC',
}
```

**Shadows (tailwind.config.ts)**:
```typescript
boxShadow: {
  'neumorphic': '9px 9px 16px rgb(163,177,198,0.6), -9px -9px 16px rgba(255,255,255,0.5)',
  'neumorphic-hover': '12px 12px 20px rgb(163,177,198,0.7), -12px -12px 20px rgba(255,255,255,0.6)',
  'neumorphic-inset': 'inset 6px 6px 10px rgb(163,177,198,0.6), inset -6px -6px 10px rgba(255,255,255,0.5)',
  'neumorphic-inset-deep': 'inset 10px 10px 20px rgb(163,177,198,0.7), inset -10px -10px 20px rgba(255,255,255,0.6)',
  'neumorphic-sm': '5px 5px 10px rgb(163,177,198,0.6), -5px -5px 10px rgba(255,255,255,0.5)',
}
```

**Typography**: Configure Plus Jakarta Sans and DM Sans via Google Fonts

### 3. i18n Configuration
- Set up next-i18next with locales: `['en', 'es']`
- Create translation JSON files for all content
- Implement language detection middleware:
  - Check `Accept-Language` header
  - Fallback to `navigator.language` on client
  - Default to 'en' if undetected

### 4. Core Components (Neumorphism Style)
**Button**:
- Extruded shadow by default
- Hover: lift + enhanced shadow
- Active: pressed (inset) state
- Rounded: `rounded-2xl` (16px)

**Card**:
- `rounded-[32px]` with extruded shadow
- Hover: `-translate-y-2` + hover shadow
- Nested depth for feature cards

**Input**:
- Inset shadow by default
- Focus: inset-deep + accent ring
- `rounded-2xl`

### 5. Pages to Create
**Home Page (`[locale]/page.tsx`)**:
- Hero section with app visual
- Features section (3-4 cards with nested depth)
- Download/CTA section
- Footer with links to privacy/terms

**Privacy Policy (`[locale]/privacy/page.tsx`)**:
- Full privacy policy content in both languages
- Neumorphism card container
- Responsive typography

**Terms of Use (`[locale]/terms/page.tsx`)**:
- Complete terms content in both languages
- Same styling as privacy page

### 6. Language Detection & Routing
- Root page (`/`) redirects to detected language: `/en` or `/es`
- Middleware checks for existing locale cookie
- Fallback to browser language detection
- Language switcher in header

### 7. Responsive & Accessibility
- Mobile-first approach
- Hamburger menu for mobile navigation
- Touch targets: minimum 44x44px
- WCAG AA contrast ratios maintained
- Keyboard navigation support
- Focus visible rings on all interactive elements

### 8. Animations & Micro-interactions
- 300ms transitions (ease-out)
- Floating animation for decorative elements
- Smooth scroll for anchor navigation
- Hover scale/translate effects

### 9. Vercel Deployment
- Configure `vercel.json` for rewrites if needed
- Ensure static generation works for all pages
- Set environment variables for i18n
- Test build: `npm run build`

## Key Files to Create
1. `tailwind.config.ts` - Design tokens
2. `next-i18next.config.js` - i18n setup
3. `src/middleware.ts` - Language detection
4. All UI components in `src/components/ui/`
5. Translation JSON files
6. Three page templates with bilingual content
